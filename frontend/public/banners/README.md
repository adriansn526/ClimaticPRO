# Banner Images

Adaugă aici imaginile pentru banner slider:

- `banner-1.jpg` - Banner principal (1920x600px recomandat)
- `banner-2.jpg` - Banner secundar (1920x600px recomandat)
- `banner-3.jpg` - Banner terțiar (1920x600px recomandat)

## Specificații Tehnice

- **Dimensiune recomandată**: 1920x600px (desktop) / 800x600px (mobile)
- **Format**: JPG sau PNG
- **Calitate**: Optimizat pentru web (< 200KB per imagine)
- **Aspect ratio**: 16:5 (desktop) / 4:3 (mobile)

## Exemple de Conținut

Bannere-le pot include:
- Produse featured (ex: TCL R290 Tri-thermal ATW)
- Promoții speciale
- Branduri premium (Gree, Daikin, Midea)
- Servicii de instalare
- Oferte sezoniere
